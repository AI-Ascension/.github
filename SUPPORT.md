# Support

## Where to ask

- **Questions, defects, observations, doubtful labels, and proof recipes:** open an issue in the
  relevant repository using one of the [issue forms](https://github.com/AI-Ascension/.github/issues/new/choose).
  The same forms appear in every `AI-Ascension` repository. If you do not know which repository, use
  this one.
- **Security or conduct concerns:** never a public issue; follow [SECURITY.md](SECURITY.md).
- **Before asking about behavior:** check the [evidence page](https://ai-ascension.github.io/evidence.html).
  If a claim is labeled `unverified`, the answer is "not checked yet", and an issue that asks for
  the check is welcome.

There is no chat channel, no paid support, and no guaranteed response time. Maintainers answer as
their time allows.

## What to include

- The repository and commit (or the site page URL) you were looking at.
- What you did: the exact command, or the exact page action.
- What you expected and what you observed, quoted rather than paraphrased where possible.
- Your platform and Rust version if you ran anything.
- The evidence label you think applies to what you observed.

## What to leave out

Game files, save data, credentials, tokens, personal file paths, multiplayer identifiers, and any
other person's data. Redact logs before attaching them.

## What you are not asked for

Stars, follows, shares, or posts. None of them affects whether or how an issue is handled.

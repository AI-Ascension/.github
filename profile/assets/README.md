# Identity assets

The AI-Ascension identity is original work of the project: the wordmark, the rising caret glyph, the five evidence stamps, and the two banners (light and dark, 1600×400) are vector SVG with every letterform outlined to path data, so they render without any font or external request; the avatar is a 1024×1024 PNG rasterised from the same vector source. No game art, mark, or asset is used or referenced. The files here are byte-for-byte copies of the site repository's `assets/identity/` directory, and their build provenance (tooling, font instances, hashes, verification steps) is logged in that repository at `assets/identity/MANIFEST.md`. Type used for outlining is Fraunces, Bricolage Grotesque, and JetBrains Mono under the SIL Open Font License; the font files themselves are not in this repository.
